# Предметная область: интернет-магазин

## 1. Информационные сущности и обоснование

| Сущность | Обоснование |
|---|---|
| Пользователь (auth.users) | Обязательная авторизация; хранит только credentials |
| Роль (roles: ADMIN, USER) | Обязательные две группы: администраторы и пользователи |
| Профиль покупателя (profiles) | Деловые данные (ФИО, email, телефон, дата рождения) |
| Адрес доставки (addresses) | У покупателя N адресов, один по умолчанию |
| Категория / Товар | Каталог магазина; товар с остатком `stock` и ценой |
| Заказ / Позиция заказа | Покупка: шапка (покупатель, статус, сумма) + строки (товар, кол-во, цена) |
| Событие регистрации (registration_event/result, inbox/outbox) | Saga (outbox/inbox таблицы) |
| Журналы (auth_audit_log, user_audit_log, order_status_log, order_audit_log) | Обязательное журналирование действий пользователей |

## 2. Функции системы (обязательные выделены)

- **(О) Авторизация**: signup → login (JWT access/refresh) → refresh; JWKS для сервисов.
- **(О) Управление пользователями**: CRUD профилей; ADMIN - все, USER - только свой;
  блокировка/активация/удаление с отзывом доступа в auth.
- **(О) Журналирование**: каждое действие (signup/login/refresh, CRUD, смена статуса
  заказа) пишется в audit-таблицы; есть выборки по пользователю,
  действию, топ активности.
- Каталог: CRUD товаров/категорий (создание/изменение - ADMIN), витрина с фильтрами.
- Заказы: создание (проверка покупателя по REST), смена статусов
  `CREATED→PAID→SHIPPED→DELIVERED`, отмена с возвратом остатков, мягкое удаление,
  история статусов, аналитика (выручка, топ товаров, средний чек).
