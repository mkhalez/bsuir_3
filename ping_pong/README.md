# Neon Pong

Пинг-понг на Python с графикой на Tkinter. Игрок управляет левой ракеткой, справа играет ИИ. Матч идёт до 7 очков.

## Что нужно

- Python 3.8 или новее
- Tkinter (входит в стандартную поставку Python на Windows и macOS)

Проверить, что всё установлено:

```bash
python3 --version
python3 -c "import tkinter; print('Tkinter OK')"
```

Если Tkinter отсутствует:

```bash
# Ubuntu / Debian
sudo apt install python3-tk

# Fedora
sudo dnf install python3-tkinter

# Arch Linux
sudo pacman -S tk
```

## Запуск

Из корня репозитория:

```bash
cd ping_pong
python3 ping_pong.py
```

На Windows вместо `python3` обычно используется:

```powershell
python ping_pong.py
```

Запускать нужно в графической сессии (не по SSH без проброса X11). Игра откроется в отдельном окне.

## Управление

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓` | Движение ракетки |
| `W` / `S` | Альтернативное движение |
| `Space` | Пауза / продолжить |
| `R` | Начать заново |
| `Enter` | Рестарт после окончания матча |
| `Esc` | Выход |

## Правила

- Отбивайте мяч ракеткой; чем ближе к краю ракетки удар, тем круче угол отскока.
- После каждого удара мяч немного ускоряется.
- Первый, кто наберёт 7 очков, побеждает.
